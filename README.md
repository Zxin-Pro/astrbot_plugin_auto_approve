# astrbot_plugin_auto_approve v2.0.0

入群自动审核 + 防刷屏禁言 二合一插件（核心逻辑取自 [QQ群智能守护者](https://github.com/zcj-ui/astrbot_plugin_group_guardian)，MIT，精简为无 WebUI/无数据库 的轻量独立插件）

> 仅支持 aiocqhttp（OneBot v11 / NapCat / LLOneBot）平台

## 入群自动审核

监听「申请加群」事件，按以下优先级处理验证答案（设置了验证问题时只匹配用户填写的答案，问题原文不参与匹配，避免误判）：

1. **拒绝词** —— 命中即拒绝（优先级最高）
2. **通过词** —— 默认优先于广告特征拦截
3. **广告特征拦截** —— 微信/QQ联系方式、外链、刷单兼职返利、邀请码注册等引流话术
4. **LLM 智能审核**（可选）—— 词库未命中时交 LLM 结合答案判断 accept/reject/manual，调用失败自动回退本地规则，广告命中仍拒绝
5. **默认动作** —— 转人工（不介入）/ 直接通过 / 直接拒绝

审核结果可发群通知（申请人、验证信息、处理原因）。

## 防刷屏禁言

按（群，用户）追踪消息时间戳，滑动窗口检测，任一档超限即禁言：

- **三档速率**：每秒（默认5）/ 每分钟（默认20）/ 每小时（默认60），设 0 关闭该档
- **夜间独立阈值**：支持跨天时段（如 23→6），三档可单独覆盖
- **重复消息检测**：默认 120 秒窗口内同一内容第 3 次触发（纯图片/表情等占位符不算内容）
- **长文本检测**：可选单条超长字数上限（默认关）
- **处罚**：禁言（默认 600 秒）+ 可选撤回窗口内消息 + 群通知；处罚后进入冷却期，期间积压消息静默吸收不重复处罚
- **豁免**：群主/管理员默认豁免（带 10 分钟缓存，不频繁查 API）；OneBot 重复推送的事件自动去重
- 所有消息类型均计入（文本/图片/转发/JSON 等）

## 配置说明

全部通过 AstrBot WebUI 插件配置页修改，支持热重载。`group_whitelist` 留空时对全部群生效。

## 群管指令

仅 AstrBot 管理员或群主/群管理员可用（`admin_commands_enabled` 开关控制，默认开）：

| 指令 | 说明 |
| ---- | ---- |
| `/禁言 <@某人或QQ号> <分钟>` | 禁言指定成员，如 `/禁言 @张三 30` 或 `/禁言 123456 30` |
| `/解禁 <@某人或QQ号>` | 解除禁言 |
| `/踢人 <@某人或QQ号>` | 将成员移出群聊 |

## 与 v1.x 的关系

v2.0.0 完全重写：原「白名单/黑名单/全自动审批」模式替换为守护者同款的规则链审核 + 防刷屏禁言。
